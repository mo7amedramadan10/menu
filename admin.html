إعداد لوحة التحكم

الخطوة دي بيعملها صاحب الحساب مرة واحدة (أو لما المفتاح تنتهي صلاحيته). بعدها الدخول بيبقى باسم المستخدم وكلمة السر بس، من أي جهاز.

1) اعمل مفتاح (Token) من GitHub:

  1. افتح صفحة إنشاء Token.
  2. في Token name اكتب menu admin، وفي Expiration اختار أطول مدة متاحة.
  3. في Resource owner اختار mixateg.
  4. في Repository access اختار Only select repositories ثم menu.
  5. في Permissions ← Repository permissions ← Contents اختار Read and write.
  6. دوس Generate token، انسخه، والصقه هنا.

2) اختار اسم مستخدم وكلمة سر للدخول:

⚠️ فيه حسابات موجودة بالفعل. الإعداد من جديد هيمسحها ويعمل الحساب ده بس (تقدر تضيف الباقيين تاني من جوه).
